Squarespace was built design-first, and its commerce backend reflects that priority. Product and inventory data is intentionally simpler than a platform like Shopify or WooCommerce — a flat quantity count per variant, no native multi-location inventory — and third-party integrations have historically gone through Squarespace's Extensions marketplace rather than deep custom API access. That's changed somewhat with Squarespace's own Commerce APIs (Orders, Inventory, Products), but it still means a fulfillment integration for Squarespace looks different than one for a platform built API-first.

## A Simpler Inventory Model Has Real Fulfillment Implications

Squarespace tracks inventory as a single quantity per product variant, without a native concept of multiple warehouse locations behind that number. For most Squarespace sellers using one fulfillment partner, this is exactly the right level of complexity — there's nothing to reconcile across locations. But it does mean that if you ever want to split inventory across two 3PLs or a warehouse plus in-house stock, that logic has to live outside Squarespace itself, since the platform's own inventory field won't represent it natively. DeliveryGroup can act as that single source of truth even if you're technically holding some stock elsewhere, syncing back one accurate number rather than letting Squarespace's flat count drift from reality.

## Orders API and Extension-Based Integration

DeliveryGroup connects to Squarespace through its Commerce Orders API, pulling new orders as they're placed and pushing tracking and fulfillment status back so customers get automatic shipping notifications through Squarespace's own notification system. For stores that got their integration set up through a Squarespace Extension rather than a direct API connection, the practical difference is mostly in setup — the resulting order flow and inventory sync work the same way once configured.

## Branded Unboxing Fits Squarespace's Design-First Sellers

Squarespace disproportionately attracts sellers who've invested real effort in visual brand identity — the platform's own value proposition is built around design quality. That makes the packaging experience matter more than it might on a lower-price marketplace: a plain brown box with a wrinkled invoice actively contradicts the polish a Squarespace store promises. DeliveryGroup supports custom boxes and mailers, branded tissue paper, printed inserts, and consistent packing instructions so every order matches the brand experience your site already sets up — sent to the warehouse once, applied to every order after that.

## Squarespace Scheduling and Service-Based Sellers

Some Squarespace Commerce stores sell a mix of physical products and services booked through Squarespace Scheduling. Fulfillment only applies to the physical side, but if your catalog mixes both, it's worth confirming during setup that only physical-product orders route to the warehouse — a detail that's easy to overlook when a single Squarespace site handles both booking and shopping.

### Does this work with Squarespace's native Commerce APIs?

Yes — the integration connects through Squarespace's Commerce Orders API for order sync and tracking pushback.

### What if my store uses a fulfillment Extension instead of a direct API setup?

The resulting order flow works the same either way; the difference is mostly in initial setup.

### Can you support branded packaging for a design-focused Squarespace store?

Yes — custom boxes, mailers, branded tissue paper, and printed inserts are all supported, with packing instructions applied consistently to every order.

### My site mixes Squarespace Scheduling with Commerce — does that cause issues?

No, as long as it's flagged during setup so only physical-product orders route to the warehouse, not service bookings.

### Can I split inventory between DeliveryGroup and another location?

Yes, though since Squarespace itself only tracks a single flat quantity per variant, that split needs to be managed on the fulfillment side so the number Squarespace shows stays accurate.
